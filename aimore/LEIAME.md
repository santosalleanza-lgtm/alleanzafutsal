# Aimoré Performance: site de página única

Site do Aimoré Personal: objetivos, programas digitais (Hotmart), consultoria online (MFIT),
modalidades, autoavaliação de 3 minutos e dúvidas. Não precisa de banco de dados.

## Subir no Netlify (conta nova)
- **Deploy manual:** Add new site → Deploy manually → arraste a **pasta `aimore`**.
- **Pelo GitHub:** Import from Git → este repositório → Base directory `aimore`, Publish directory `aimore`, sem build.
- Nome sugerido do site: **aimoreperformance** → https://aimoreperformance.netlify.app
